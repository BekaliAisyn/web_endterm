ENDTERM / SE-2517

I started with five page roles: introduction, project collection, personal context, learning notes, and contact. Each page has one clear purpose. Semantic header, nav, main, and footer landmarks make the structure easier to navigate.

A consistent structure makes later design decisions simpler.

Bootstrap rows contain responsive columns: col-md-6 creates two columns from the medium breakpoint, while col-lg-4 creates three on larger screens. The hero uses col-lg-6 for an even split and naturally stacks on smaller screens.

Test real content at multiple widths, not just the desktop layout.

A project filter updates both the visible cards and the result count. The save button exposes its state with aria-pressed and persists only project IDs in localStorage. A friendly empty state explains what to do when nothing is saved.

Every action should make its result understandable.

These notes expand using jQuery slideToggle. Each button updates aria-expanded and points to its panel using aria-controls. The animation duration becomes zero when prefers-reduced-motion is enabled.

An effect should help orientation without becoming an obstacle.

The contact demo checks a name, email, topic, message, and consent before showing a local confirmation. It uses the browser’s constraint validation API, Bootstrap feedback styles, and a live status message. Nothing is sent to a server.

Be precise about what a form actually does.
